# 播报

本目录统一存放所有模块的语音播报，不按游戏划分子目录。目前包含三消使用的 6 个英文 WAV：

- `good.wav`、`great.wav`、`excellent.wav`、`amazing.wav`、`unbelievable.wav`：五档赞美播报。
- `bonus_time.wav`：Bonus Time 奖励阶段开场播报。

这些文件为已导入的表演配音，不适用 `../effects/` 的脚本原创合成声明。`scripts/generate_match_praise.ps1` 仅使用 Windows 系统语音生成开发对照素材，默认输出到 `temp/match_praise_tts`，不会覆盖本目录。

播报使用独立播放器，跟随首页设置页的“播报”开关；所有游戏共享 `00.common/voice` 设置，不在游戏页面放置独立按钮。音效与音乐分别存放在 `../effects/`、`../music/`，各自使用独立的音频设置。原生端复用项目 JSON 存储，Web 设置使用浏览器 localStorage；存储不可用时游戏仍可正常运行。

三消目标达成后先展示本次行动的稳定结算帧并完成赞美播报，再进入 Bonus Time；奖励开场语音也需播放结束后，才开始自动消除和剩余步数转特效，避免转换音效与开场播报重叠。普通动画和减少动画模式均保留这段顺序。等待期间仍属于结算忙碌状态，不开放下一步，也不提前显示终局重开按钮或联机终局展示；工具栏主动重开仍可取消旧局。静音、切后台可取消当前播报，重开、同步重置和退出会取消旧局等待；设备未回报播放结束时，每段播报均使用 5 秒超时保护，避免卡住奖励结算。
