# 消消乐音效

本目录的 18 个 WAV 音效均由项目内的 Dart 脚本原创合成，不包含第三方录音、采样或语音，沿用项目许可证。

在项目根目录重新生成：

```sh
dart run scripts/generate_match_audio.dart
```

格式为 22,050 Hz、单声道、16 位 PCM WAV。四档消除音随连锁升高；行列、炸弹、彩虹、碎冰与结算分别使用独立音色。

- `entrance.wav`：进入页面及重开时的专属棋盘入场音。约 0.50 秒，两下低中频同音木质敲击，停顿后以同时发声的短和弦收尾。
- `appear.wav`：双彩虹全清等情况后的全盘补齐动物。约 0.255 秒，两下快速下滑的气泡音，不再使用上行音阶。
- `bonus.wav`：奖励阶段及剩余步数转换的合成提示音。约 0.39 秒，高频一高一低双铃，通过非整数倍分音和轻微拍频形成金属感，与开局、补齐的音色和节奏分离。
- `fall.wav`：普通消除后的局部补块。

上述三种提示分别使用木质、气泡和金属铃音色；其他音效保留原有合成参数，`won.wav` 的胜利旋律不变。

英文赞美与 Bonus Time 语音位于相邻的 `match_praise` 目录，使用独立播放器，不适用本目录的原创素材声明。

消除与入场音效跟随首页设置页的“音效”开关，英文赞美和 Bonus Time 由独立的“播报”开关控制；所有游戏共享 `00.common/audio`、`00.common/voice` 设置，不再在游戏页面放置独立按钮。原生端复用项目 JSON 存储，Web 设置使用浏览器 localStorage；存储不可用时游戏仍可正常运行。

目标达成后先展示本次行动的稳定结算帧并完成赞美播报，再进入 Bonus Time；减少动画模式也保留这段顺序。等待期间仍属于结算忙碌状态，不开放下一步，也不提前显示终局重开按钮或联机终局展示；工具栏主动重开仍可取消旧局。静音、切后台可取消当前播报，重开、同步重置和退出会取消旧局等待；设备未回报播放结束时使用超时保护，避免卡住奖励结算。
