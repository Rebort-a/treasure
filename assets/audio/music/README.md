# 飞船与坦克背景音乐

`spaceship.wav` 与 `tank.wav` 是项目脚本原创编曲与合成的循环音乐，不含第三方音乐、录音或采样，沿用项目许可证。

```sh
dart run scripts/generate_game_music.dart
```

格式：22,050 Hz、单声道、16 位 PCM WAV。每首为 16 小节；太空主题为 112 BPM，坦克主题为 124 BPM。合成器将尾音回卷到循环开头，播放器以循环模式持续播放。

音乐独占一个播放器，不会被射击或爆炸音效打断。仅在游戏运行、页面可见、应用位于前台且用户开启音乐时播放；暂停后保留播放位置，退出后释放资源。音乐开关及音量与音效独立，保存于各游戏的 `music` 设置；Web 使用浏览器 localStorage，禁用浏览器存储时降级为本次页面会话设置。
