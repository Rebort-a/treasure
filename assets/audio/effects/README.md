# 音效

本目录统一存放所有模块的短音效，不按游戏划分子目录。26 个 WAV 均由项目内的 Dart 脚本原创合成，不包含第三方录音、采样或语音，沿用项目许可证。

在项目根目录重新生成，两条命令分别生成不同的音效集合，均输出到本目录：

```sh
dart run scripts/generate_game_audio.dart
dart run scripts/generate_match_audio.dart
```

格式：22,050 Hz、单声道、16 位 PCM WAV。`generate_game_audio.dart` 生成 14 个通用短音效，`generate_match_audio.dart` 生成 12 个消除、入场和结算等音效；文件名保持不变，重新生成不会覆盖另一组资源。

## 通用行为反馈

通用音效包括轻点、落子、翻面、吃子、成功、错误、射击、受击、拾取、跳跃、施法、爆炸、胜利和失败。

三消的选择、交换、无效交换、炸弹、局部补块和转换事件也复用 `tap`、`flip`、`error`、`explosion`、`move` 和 `cast`，不再保留近似的专属副本。通用资源保持原有内容，通过 `MatchSound.asset` 映射，不改变三消内部的事件名称及触发场景：

| 三消事件 | 共享资源 | 场景 |
| --- | --- | --- |
| `select` | `tap.wav` | 选中棋子 |
| `swap` | `flip.wav` | 有效交换 |
| `invalid` | `error.wav` | 无效交换回退 |
| `bomb` | `explosion.wav` | 炸弹消除 |
| `fall` | `move.wav` | 普通局部补块 |
| `transform` | `cast.wav` | 转换连线及转换完成 |

合并以已有通用资源为准，因此其他游戏声音不变，三消对应六类短反馈统一为通用版本；删除的专属 WAV 不再由脚本生成。本目录共保留 26 个 WAV，相比去重前的 32 个减少 49,010 字节原始资源，不等同于压缩后安装包的减少量。本次目录整理仅移动资源，不改变音频内容。

## 消除、入场和结算反馈

三消使用 18 类声音事件：12 类使用消除、入场和结算等音效，其余 6 类复用上述通用反馈。四档消除音随连锁升高；行列、彩虹、碎冰与结算保留三消专属声音。

- `entrance.wav`：进入页面及重开时的专属棋盘入场音。约 0.62 秒，G–E–C 三音下行，与原失败音效交换了声音内容。
- `appear.wav`：双彩虹全清等情况后的全盘补齐动物，以及没有合法交换时自动重排后的棋盘展示。约 0.255 秒，两下快速下滑的气泡音，不再使用上行音阶；减少动画时，同一次最终展示中的全盘补齐与重排合并为一次提示。
- `bonus.wav`：奖励阶段剩余步数转换的合成提示音，开场语音播报结束后，仅在步数转换完成时播放。约 0.39 秒，高频一高一低双铃，通过非整数倍分音和轻微拍频形成金属感，与开局、补齐的音色和节奏分离。
- `lost.wav`：步数耗尽且目标未完成，本次行动全部结算结束后播放一次。约 0.50 秒，两下低中频同音木质敲击，停顿后接短和弦，与原入场音效交换了声音内容；普通动画和减少动画模式均适用，刷新和重复快照不重播。

入场、补齐、奖励和失败分别使用下行三音、气泡、金属铃和木质音色，`won.wav` 的胜利旋律不变。

## 播放与设置

播放底层位于 `00.common/service/sound_service.dart`，每个游戏页面管理后台停止和资源释放；音效开关统一由首页设置页控制，所有游戏共享 `00.common/audio` 设置。全局音频偏好位于 `audio_preferences.dart`，退出或切换游戏不会重置偏好。原生端沿用 JSON 文件，Web 音频设置使用浏览器 localStorage；浏览器存储不可用时不影响游戏。

只在已确认的游戏行为发生时发布音效事件，渲染、初始快照、重复消息和插值不发声。实时游戏的射击、受击及爆炸另有频率限制。

英文赞美与 Bonus Time 语音统一位于 `../voice/`，使用独立播放器和 `00.common/voice` 播报设置，不适用本目录的原创素材声明；循环背景音乐位于 `../music/`。
