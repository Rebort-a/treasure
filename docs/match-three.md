# 18 消消乐

## 游戏规则与随机生成

- 8×8 棋盘、六种原创动物。每局随机生成棋盘、两种收集目标、冰层、分数目标和步数，不使用预设关卡。
- 交换相邻动物形成横/竖三连。无效交换不扣步数；一次交换的所有连锁只扣一步。
- 四连生成直线特效，五连生成彩虹，T/L 形生成炸弹。特效可连锁触发；两个特效可直接交换。
- 动物消除后下落补齐，冰层留在格子上。没有合法交换时自动免费洗牌。
- 同时完成分数、动物收集和清冰目标获胜；步数用完且目标未完成则失败。随机挑战不承诺每个生成目标组合都能在给定步数内完成。

随机序列的状态随棋盘序列化；使用整数乘积小于 2^53 的算法，使 VM/Web 的重演一致。棋盘生成、连锁结算和洗牌均有有界兜底，避免无限循环。

## 为什么不是第三种底层联机协议

现有双人回合制是“前手/后手＋一个对手”，实时游戏是“多个参与者持续发送动作”。本游戏是**N 人合作回合制**：

- 一份共享棋盘、一份剩余步数与共同胜负，而非各自的棋盘。
- 成员按 ID 顺序循环轮转，仅当前成员有操作权。
- 不需要帧同步，但需要统一随机补块结果、动作排序与中途入局同步。

因此保留双人 `NetTurnEngine` 的兼容性，将原实时引擎的成员/入局/发布者逻辑抽成 `NetMultiEngine`。`NetRealEngine` 沿用原回调协议；`NetMultiTurnEngine` 复用同一多人入局事务，实现合作回合的快照屏障。房间仍标识为 `RoomGameMode.turn`，没有新增消息类型或更改既有房间编号。

## 合作回合的提交流程

1. 聊天室中至少两人匹配，创建同一个 gameId。单局页面通过 `OnlineGameHost` 创建游戏 Manager，不关闭房间连接。
2. 发布者生成随机局面，资源同时携带名单、名单修订、回合修订和当前操作者。
3. 每个成员装载快照后回复应用层 `ready`；发布者收齐当前名单的 ready，再广播 `go`。
4. 当前操作者发送 `action(revision, from, to)` 请求。请求方不乐观修改自己的棋盘。
5. 发布者检查发送者、修订号、相邻关系与消除合法性，完成整步结算，轮转操作者并发布下一份完整快照。
6. 所有成员重新同步，再开放下一步。非法交换不扣步数，也不轮转。

ACK、重发、去重和旧 gameId 隔离沿用 `SocketClient`；search 不重发。应用层修订还会拒绝同局迟到动作，防止一个合法操作在下一轮再次生效。

多人同时准备时，合作匹配短暂汇集搜索者，由较小 ID 发起，其他人优先接受已有队伍邀请。首次匹配期间其余准备请求移交给多人发布者，再逐个完成入局事务，避免沿用双人配对策略将六人拆成三份棋盘。

## 中途加入与离开

- 中途加入复用现有入局事务，不创建新棋盘，不重新生成随机内容。新成员接收当前目标、棋盘、随机状态和剩余步数。
- 加入/退出同样需要名单修订和新的同步屏障，不能按房间总人数计算对局参与者。
- 普通成员离开时跳过其回合；发布者离开后由剩余成员接管，保留 gameId 和已有共同局面。
- 开局至少两人；其他成员离开后，最后一人可以继续，不要求即时结束合作挑战。
- 重开在本地模式可直接随机新局。联机结束后返回聊天室重新匹配，使用新的 gameId，不在旧局内各自重开。
- 合作队伍拥有独立对局聊天记录；未参与此局的成员继续在房间聊天。

## 模块分层

```text
18.match_three/
  base/
    match_board.dart         棋盘、棋子、随机生成、结算与快照
  middle/
    match_manager.dart       选择/提示、动画帧和状态生命周期
    net_manager.dart         联机逻辑桥接，不向首页/聊天室暴露
  upper/
    local_page.dart          本地入口＋私有生命周期容器
    net_page.dart            唯一公开联机入口（StatelessWidget）
    game_view.dart           本地/联机共用游戏界面
    match_board_widget.dart  棋盘展示与交互
    animal_piece.dart        小动物 Canvas 与待机动画
```

全部 Dart 文件统一归入三层目录，不在根目录保留页面、Manager 或转发 export。层间依赖从 upper 指向 middle/base、middle 指向 base，不允许下层依赖上层。首页只导入 upper 层的本地和联机页面入口。

每个棋盘仅使用一个待机动画时钟，通过 CustomPainter 的 repaint 直接重绘。动画不修改游戏状态、不消耗随机数、不产生网络消息；系统减少动画设置下停用待机与结算动画。
